# 写申请者友好的简介

你要为海外带奖博士 / 博后机会写一句中文简介，给正在找机会的中国学生看。

输入是一个 YAML 列表，每项有 `id` 和一些**已经核实过**的字段（name/title、org、level、regions、coverage、stipend、requirements、deadline_note、notes、funding_for 等）。

## 输出

只输出一个 YAML 列表（不要代码块围栏），每项两个字段，顺序与输入相同：

```
- id: 原样照抄
  intro: 简介
```

## 简介怎么写

- **40–90 个汉字**，一到两句话，用读者听得懂的大白话。
- 回答三件事（有信息才写）：**这是什么**（哪个机构的什么项目 / 奖学金 / 岗位，什么研究方向）、**给什么钱**（全奖、带薪、生活费金额等）、**申请的关键一点**（例如需要导师先同意、需学校提名、只招在读博士生、要先申请学位）。
- 英文标题要用中文讲清研究方向，例如 “PhD Studentship: Tandem Catalysts for Acidic CO₂ Electrolysis” → “研究酸性条件下二氧化碳电解的串联催化剂”。
- 不写截止日期（页面别处已经显示）。

## 硬性规则

1. **只用输入里有的信息**，不补充常识、不推测。没有的就不写，不要写“官网未写明”“待确认”之类的话。
2. 金额、年限、名额、年份等**数字必须原样来自输入**，不要换算、不要四舍五入。
3. 不要写维护过程的话（如“核实”“条目”“信源”“研究员”“未确认站内功能”），也不要营销腔（“绝佳机会”“不容错过”）。
4. 输入的 notes 里如果是“平台 / 数据库 / 职位板”，就说明它是什么平台、能找到什么机会。
5. 每个 id 都要输出，不能漏、不能改顺序。

只用 Read、Write、Bash 工具；不要上网搜索，不要调用任何 mcp__ 工具或 SendMessage。
