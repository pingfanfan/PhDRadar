---
description: 从简历生成申请者画像 profile.yml 与简历要点 cv-facts.yml（只记录简历里有的事实）
argument-hint: [简历文件路径，如 cv/cv.pdf；不填就请申请者粘贴文字]
---

目标：10 分钟内从一份简历得到能驱动 `/rank` 的画像。字段说明见 `docs/profile-schema.md`，格式照抄 `profile.example.yml`。

1. **隐私先说清楚**：告诉申请者 `profile.yml`、`cv-facts.yml`、`cv/`、`applications/`、`rankings/` 已在 `.gitignore` 里，不会被提交；
   用 `git check-ignore profile.yml cv-facts.yml` 确认。如果没被忽略，先停下修好 `.gitignore`，不要写文件。
2. **读简历**：`$ARGUMENTS` 是文件路径就读它（PDF 用 Read 工具读页面）；没有就请申请者把简历文字粘贴进来。
3. **写 `cv-facts.yml`**：逐条摘录简历里的事实（学历、论文、项目、获奖、技能、工作、语言成绩），每条带 `quote`（简历原文）。
   简历上写了姓名和邮箱的，写在文件顶层的 `name`、`email`（`/apply` 文书落款要用）。
   - 只写简历里有的；不推断、不补全、不美化，不把“参与”写成“负责”，不给论文升级状态。
   - 数字（GPA、分数、指标、年份）逐个对照原文。
4. **起草 `profile.yml`**：能从简历直接得到的先填（`education`、`publications`、`projects`、`languages`），
   研究关键词：先从论文与项目题目里提 3–6 个，再扩写到 6–8 个——补上英国 / 欧洲岗位标题里真正会用的英文说法与同义说法，
   只扩写申请者方向本身，不加会匹配到别的领域的泛词（如单独的 protein、data、learning、systems）。**列给申请者确认**。
   评测显示扩写能多找到约 6% 对口的机会（docs/rank-eval.md），混进来的由 `/rank` 的 Claude 判断滤掉。
5. **对话补全**简历里通常没有的，一次问完，申请者不知道的留空：
   - 国籍；读 PhD 还是博后，最早入学时间；
   - 可接受 / 偏好 / 排除的国家；
   - 资助底线（不限 / 至少部分 / 全奖或带薪 / 只要官网写明全奖），是否有每月最低金额；
   - 语言成绩（雅思 / 托福总分，德语水平）；
   - 是否只看官网写明中国学生可申请的；
   - 方向是否敏感（核、航天、军用材料、部分半导体与 AI 安全等，会触发出口管制 / ATAS / 安全审查）——解释这个字段只影响提醒和降分；
   - 一段研究兴趣描述（2–4 句，用申请者自己的话）。
6. 写出 `profile.yml`，然后运行 `python scripts/rank.py --stdout --top 5` 试排一次，把前 5 条和被排除的主要原因给申请者看；
   如果推荐很少或明显不对口，和申请者一起调整关键词（加同义词、英文写法）或放宽条件，再试一次。
7. 结束时告诉申请者：下一步运行 `/rank` 生成完整排序；画像随时可以直接改 `profile.yml`。
