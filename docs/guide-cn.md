# 中国学生申请海外带奖 PhD 指南

> 本文讲“去哪找 + 能不能拿 + 什么时候申”。具体信源见 [SOURCES.md](../SOURCES.md)。政策随时变化，**一切以官方页面为准**。

## 1. 先搞清楚：不同地区的“带奖”是什么意思

| 地区 | 资助模式 | 招生方式 | 主要时间窗口 |
| --- | --- | --- | --- |
| 美国 | 录取即带奖为主：学费全免 + 生活费（TA/RA/Fellowship） | 按项目（program）统一申请，委员会录取；套磁有帮助但不是必须 | 9–12 月提交，次年 2–4 月出结果 |
| 加拿大 | 学校最低资助保障 + 导师经费；国际生学费差额部分学校已取消 | 多数需先找到导师 | 12–1 月截止为主 |
| 英国 | Studentship：学费 + 生活费；**大量名额只覆盖本土学费** | 按课题（project）申请或 DTP/CDT 统一招生 | 11–3 月集中，全年滚动 |
| 荷兰 / 北欧 / 瑞士 / 比利时 | **带薪雇员**：签劳动合同，有工资和社保 | 按岗位（vacancy）申请，导师直招 | 全年滚动，岗位开放 2–6 周 |
| 德国 | 带薪岗位（TV-L E13 部分时间）或奖学金（DAAD、研究生院） | 岗位直招 / IMPRS、RTG 等统一招生 | 全年滚动；IMPRS 多在秋冬 |
| 法国 | Contrat doctoral（3 年合同）或 CIFRE 企业博士 | 博士生院按课题发布，春季竞争 | 3–6 月集中 |
| 意大利 | Borsa di dottorato（奖学金名额） | 每年各校发布 bando，考试/面试 | 4–7 月发布 |
| 澳洲 / 新西兰 | RTP 等奖学金（学费 + 生活费） | 先联系导师，再申请奖学金轮次 | 多数学校每年 2 轮 |
| 香港 / 新加坡 | HKPFS、校级奖学金；SINGA、NUS/NTU 奖学金 | 按项目申请，导师意见很重要 | 香港 9–12 月；SINGA 6/1 与 12/1 |
| 日本 / 韩国 | MEXT、GKS、OIST 全奖、导师 RA | 先联系导师；政府奖学金有固定窗口 | 春季为主 |
| 中东 | KAUST、MBZUAI 录取即全奖 | 统一申请 | 秋冬截止 |

**结论**：不要只盯一个平台。美国看项目官网 + 套磁；英国看 FindAPhD 的 “Students Worldwide” 筛选；欧洲大陆每周刷各国招聘门户；任何地区都要关注导师个人渠道。

## 2. 中国学生特有的坑

### 2.1 “国际生资格”与学费差额
- 英国 UKRI 资助自 2021 年起可招国际生，但通常有比例上限（约 30%），且有的项目只补到本土学费，差额要学生自付。看清 “Eligibility / Funding notes”。
- 澳洲、加拿大、新西兰的奖学金也经常区分 domestic / international，名额差异很大。

### 2.2 CSC 公派奖学金
- 优点：国家资助生活费，可作为“自带经费”打动导师；很多海外高校有 CSC 联合奖学金（学校出学费，CSC 出生活费）。
- 限制：须签协议、学成回国服务 2 年；部分欧洲高校（如德国 FAU 自 2023 年起）已不再接收**仅由 CSC 资助**的博士生，部分国家/学校对 CSC 资助生有额外审查。申请前务必和导师、学校确认。

### 2.3 安全审查与出口管制
- **美国**：2020 年第 10043 号总统公告限制与“军民融合”相关院校/背景的中国研究生签证；2025 年以来签证政策又有多轮收紧和变动。本科/硕士在“国防七子”等院校者尤其要提前评估。
- **英国**：非欧洲经济区学生读部分理工科敏感方向需申请 **ATAS** 证书，审批可能需要数周到数月。
- **荷兰 / 德国 / 北欧 / 瑞士等**：涉及敏感技术（半导体、量子、航空航天、AI 安全等）的岗位越来越多做知识安全/出口管制审查，可能延长入职时间或直接排除特定背景。
- 建议：选方向时把“敏感学科风险”作为一个打分维度；简历如实，不要隐瞒背景。

### 2.4 语言与材料
- 英语岗位通常要求雅思/托福，部分欧洲岗位接受英文授课学位证明。
- 欧洲岗位常要硕士学位（或入职前取得），本科直博更适合美国、英国（部分）、香港、新加坡、KAUST、OIST、ISTA。

## 4. 个人信源：平台之外的机会

很多带奖名额**从不挂到平台**，只出现在导师自己的渠道里：

1. **从论文找人**：近 3 年你读过/引用过的论文 → Google Scholar / Semantic Scholar 查作者 → 看主页 “Openings / Prospective students / Join us”。
2. **新晋助理教授（AP）**：刚入职的 AP 有启动经费、最需要学生。关注每年的新 AP 名单和招生汇总（见 SOURCES.md「导师招生汇总」）。
3. **社交媒体**：在 X / Bluesky / LinkedIn 保存搜索 “PhD position” + 你的方向 + “funded”。
4. **学科邮件列表**：Connectionists（ML）、EvolDir（进化生物）、ECOLOG-L（生态）等，订阅后每天都有新岗位。
5. **中文社区**：小木虫、知乎、小红书上的华人教授招生帖，注意核实发帖人身份与时间。
6. **暑研 / 实习**：KAUST VSRP、Summer@EPFL、ISTernship、OIST 实习等，表现好常直接转为博士录取。

## 5. 一年时间线（以次年秋季入学为例）

| 时间 | 事项 |
| --- | --- |
| 前一年 3–6 月 | 确定方向和地区，整理导师清单；申请暑研；CSC 项目关注年度简章 |
| 6–9 月 | 准备语言成绩、CV、研究计划；开始套磁；SINGA 6 月轮次 |
| 9–12 月 | 美国、香港（HKPFS 约 12 月 1 日）、英国名校、ELLIS（10 月）、IMPRS、OIST（11 月中）等集中截止；SINGA 12 月轮次 |
| 1–3 月 | 英国 studentship、ISTA、澳洲奖学金轮次；面试季；CSC 申报 |
| 全年 | 欧洲大陆带薪岗位滚动发布——**每周固定刷一次** |
